## Mini_project_CSC
## CSC03A3 Mini Project
## Team name: Syntax Labs
## Project name: GraphInk

### Steps for executing the project from the jar file.<br>
<b>Step 1</b>: Navigate to the jar file. <br>
<b>Step 2</b>: Inside the bin folder run the command '--module-path "C:\javafx-sdk-21\lib" --add-modules javafx.base,javafx.controls,javafx.fxml,javafx.graphics,javafx.media'.<br>


### Steps for executing the project from eclipse <br>
<b>Step 1</b>: Setup javafx.<br>
<b>Step 2</b>: add the *gs-core-2.0.jar* and *gs-ui-javafx-2.0.jar* jar files to build path. These are the jar files used by GraphStream to render graphs in javafx.<br>
<b>Step 3: Add the VM arguments for javafx '--module-path "C:\javafx-sdk-21\lib" --add-modules javafx.base,javafx.controls,javafx.fxml,javafx.graphics,javafx.media'.<br>
<b>Step 3</b>: Run the program.
